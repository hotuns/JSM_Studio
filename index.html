01 — 键鼠游戏

游戏不支持手柄，
但我想用手柄玩。

把移动、跳跃、交互、开火等动作映射到手柄按键和摇杆上，保存成这款游戏的配置，下次直接加载。

02 — 体感视角

我想用体感，
控制游戏视角。

游戏允许混合输入时，保留原生手柄操作，再用体感控制鼠标视角。若混合输入出现冲突，可以尝试将战斗操作统一映射为键鼠，并在游戏内验证效果。

03 — 顺手的配置

想按自己的习惯玩，
又不想从零折腾。

按游戏动作设置按键，调整体感灵敏度与防抖，或从社区导入配置再修改。游戏名称、动作和映射可以用一个 TXT 分享。

如果游戏原生手柄体验已经很好，你也不需要体感或自定义映射，通常无需额外运行 JSM Studio。

QUESTIONS / 常见问题
我什么时候需要使用 JSM Studio？

当你想用手柄玩键鼠游戏、想用体感控制视角，或希望按自己的习惯调整操作时，可以使用 JSM Studio。它提供按游戏动作配置、体感调校和社区配置导入，帮助你减少配置工作。如果原生手柄操作已经满足需求，通常不必额外运行。

所有手柄都支持体感吗？

需要手柄本身提供陀螺仪数据，并且当前连接模式可被映射引擎读取。支持情况取决于型号、固件与连接方式，可先在设备页面确认传感器输入。

游戏不支持手柄和鼠标同时输入怎么办？

可将手柄按键与摇杆一起映射成键鼠输入，再将体感映射为鼠标。需要按游戏的键位设置核对映射，并在游戏中测试输入切换和操作行为。

可以自动切换菜单与战斗操作吗？

可以分别指定系统光标显示、隐藏时加载的配置，或选择“不切换”；隐藏时也可恢复切换前配置。它依据 Windows 系统光标状态，不直接识别战斗或菜单。游戏自行绘制光标、或手柄操作导致菜单光标隐藏时，可能不适合使用自动切换。

配置可以继续手动编辑吗？

可以。JSM Studio 保留高级设置和配置源码编辑。游戏配置使用 # 注释记录游戏名与动作，其余仍是普通 JSM 命令，便于导出分享。

如何反馈问题或贡献配置？

在 GitHub Issues 反馈问题时，请附上版本、手柄型号、连接方式和复现步骤。分享配置请参照社区目录的说明，提供 TXT、适用设备与游戏键位要求。
