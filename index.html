接上手柄。

01

选择你的设备，确认按键、摇杆与体感输入正常。实际功能取决于手柄、连接模式与固件。

QUESTIONS / 常见问题
所有手柄都支持体感吗？

需要手柄本身提供陀螺仪数据，并且当前连接模式可被映射引擎读取。支持情况取决于型号、固件与连接方式，可先在设备页面确认传感器输入。

游戏不支持手柄和鼠标同时输入怎么办？

可将手柄按键与摇杆一起映射成键鼠输入，再将体感映射为鼠标。需要按游戏的键位设置核对映射，并在游戏中测试输入切换和操作行为。

配置可以继续手动编辑吗？

可以。JSM Studio 保留高级设置和配置源码编辑。新版游戏配置使用 # 注释记录游戏名与动作，其余仍是普通 JSM 命令，便于导出分享。

如何反馈问题或贡献配置？

在 GitHub Issues 反馈问题时，请附上版本、手柄型号、连接方式和复现步骤。分享配置请参照社区目录的说明，提供 TXT、适用设备与游戏键位要求。
