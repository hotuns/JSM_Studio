# JSM Studio v0.2.5

本次更新重构桌面界面，以游戏动作配置为核心，并新增社区配置、光标自动切换和驱动组件管理。

- 重构主界面与导航，统一配置保存、应用和运行状态提示，保留高级 JSM 配置编辑。
- 新增游戏配置向导和动作映射界面，可自定义游戏名、添加、设置和删除动作。游戏名称、动作列表和映射保存在同一个 JSM TXT 文件中，便于导出分享。
- 新增社区配置页面，支持浏览 GitHub 上的配置并导入配置库；提供官网和下载入口。
- 新增全局光标自动切换：显示、隐藏分别选择配置，两项均可设为“不切换”；隐藏时还可选择“恢复切换前配置”。旧规则自动迁移。光标状态稳定约 300 毫秒后执行，手动应用配置优先。
- 新增“设置与组件”页面，集中查看 HidHide、ViGEmBus 状态、虚拟手柄输出设置、软件更新及运行支持。
- 内置 HidHide 1.5.230 和 ViGEmBus 1.22.0 官方安装程序，未安装时可直接启动安装向导。只有驱动安装时申请管理员权限，主程序仍以普通权限运行。
- 新增 HidHide 手柄隐藏、恢复和 JSM 读取授权操作；恢复时保留用户原有的隐藏规则。提供独立 Xbox / DS4 虚拟手柄基础配置。
- 改进更新状态与错误提示，并使用可匿名访问的 GitHub 下载地址，修复发现更新后下载失败的问题。
- 移除原 JSM 文档入口，更新通用手柄示意图与中英文说明。

光标检测使用 Windows 系统光标状态；游戏自行绘制的光标可能无法识别。菜单手柄和战斗键鼠输出需要分别配置，并在目标游戏中验证。安装驱动后如提示需要重启，请重启 Windows。

引擎继续使用已验证的 JoyShockMapper 提交 `50cd0827d382bbdb6c0051576ee321ff0c0faa6d` 与 SDL 3.4.18，保留此前的体感采样卡顿修复。

Windows 用户可下载 EXE 或 MSI 安装包；已安装用户也可通过应用内更新升级。
