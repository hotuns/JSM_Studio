# JSM Studio 0.2.4-rc.1 测试说明

此版本用于验证体感映射鼠标的间歇卡顿修复，适用于 Windows x64。

## 本次改动

- 修复自动连接检查在持有采样锁时等待 20 毫秒的问题，避免设备数量未变化时仍周期性阻塞体感采样和鼠标输出。
- 使用基于 Xbox 布局绘制的通用 SVG 手柄，保留按键、摇杆、扳机和扩展按键状态显示。
- 重新布局体感控制页面，为基础设置、灵敏度和防抖参数添加作用说明与问号帮助按钮。
- 使用 SDL 3.4.18；JoyShockMapper 引擎提交为 `50cd0827d382bbdb6c0051576ee321ff0c0faa6d`。

## 安装与测试

1. 完全退出正在运行的 JSM Studio 和 JoyShockMapper，再运行测试版安装 EXE。测试不需要安装 Node.js、Rust 或编译工具。
2. 选择之前出现卡顿的同一份配置，保持手柄、连接方式和固件不变。首先不要额外增加滤波或平滑，以免影响前后对比。
3. 保持自动连接开启。先不操作摇杆、不按切换灵敏度的按键，连续缓慢转动手柄 30 秒，观察是否仍有间歇停顿和光标跳动。
4. 分别测试快速转向、按住或松开瞄准键、同时操作右摇杆，记录哪些动作还会触发异常。
5. 查看频率显示是否较旧版稳定。当前 SDL 路径主要统计引擎回调频率，不代表手柄传感器的实际报告频率。
6. 拔插接收器或重新连接手柄，检查自动连接和按键状态显示是否正常。
7. 在体感控制各分区点击问号查看说明，测试开启 One Euro 后展开参数，并确认“应用更改”和“取消”正常。

## 反馈内容

- 手柄型号、手柄与接收器固件版本、连接方式和手柄模式。
- 旧版与此测试版是否使用同一份配置。
- 卡顿是否消失；如果仍有，说明出现频率和触发动作。
- 页面显示的频率大致范围，以及问题发生时是否明显下降。
- 可复现问题的配置或简短录屏。

此版本已完成编译与代码检查，体感手感和热插拔效果仍需实际设备验证。
