# 全局光标自动切换

入口：配置库中的「自动切换」，或工具菜单中的「自动切换」。

1. 分别设置「光标显示时使用」和「光标隐藏时使用」，每项可选择一个已保存的配置，或「不切换」。
2. 「不切换」表示该光标状态不会改变当前输出；不会隐式恢复之前的配置。两项都留空也是有效规则。
3. 隐藏时额外提供「恢复切换前配置」：恢复本轮自动切换开始前的常规配置；若存在当前前台程序的 AutoLoad 规则，优先恢复该规则。
4. 勾选「启用光标切换」，点击「保存规则」。规则全局生效，保存后根据当前稳定光标状态执行一次；后续只在状态变化并稳定约 300 毫秒后执行。
5. 例如显示时选择「菜单手柄」，隐藏时选择「战斗键鼠」。两个配置分别设置自身的输出映射；规则本身不自动生成虚拟手柄输出，也不会更改 HidHide。
6. 关闭规则会恢复常规配置。旧版规则自动迁移为：显示时使用原光标配置，隐藏时恢复切换前配置。

创建的基础光标配置使用右摇杆移动鼠标，A 左键、B 右键、X 回车、Y Escape、LB / RB 上下滚动，体感灵敏度为零。可以在高级映射中调整，或直接选择自己创建的鼠标操作配置。

## 运行方式

- 使用 Windows `GetCursorInfo` 的系统光标显示状态，在 Tauri 后台以约 100 毫秒间隔读取；不依赖前端页面或窗口是否最小化。
- 有 300 毫秒稳定时间，避免光标短暂闪现导致来回切换。检测失败视为未知，不视为隐藏。
- 临时配置不写入当前配置文件、不改变编辑器选择、不清除未保存编辑，也不替换引擎的常规启动配置。
- 暂停输出时不会启用映射；体感校准和校准配置操作期间暂停自动切换。
- 手工应用、暂停输出或引擎重启优先于自动切换，丢弃旧恢复快照，并消费当前光标状态。只有下一次光标状态变化才重新触发，不会立即覆盖手工操作。
- 光标配置生效期间暂时抑制 JSM 的进程 AutoLoad。恢复时，如启用了进程规则且当前程序有匹配规则，加载该规则；否则恢复切换前保存的配置内容，然后恢复全局 AutoLoad 开关。
- 切换失败会显示错误并间隔重试，不因一次检测失败重启映射引擎。失败后会尝试恢复常规配置。
- 设置会保存在应用运行数据目录的 `cursor-switch.json` 中。它是应用级设置，不需要复制到每个游戏 TXT。

## 检测范围

检测的是 Windows 报告的系统光标显示状态。游戏自己绘制的软件光标、透明光标或未按系统方式隐藏的光标，可能与这个状态不一致。本功能不做屏幕图像识别。应在目标游戏中验证菜单和游戏视角切换时的状态。

应用必须保持运行，最小化可以继续检测。功能默认关闭，只有保存启用规则后才开始自动切换。

## 验证

Rust 单元测试：在 `JSM_GUI/jsm_gui_tauri/src-tauri` 运行：

```powershell
cargo test --lib cursor_switch::tests
```

覆盖显示/隐藏独立目标、两侧留空、旧设置迁移与显式空值保留、一次性边沿触发、手工操作优先、失败重试、短暂闪现、未知状态、关闭恢复、暂停与校准，以及临时配置的 AutoLoad 设置。还需通过目标游戏的实际系统光标状态验证。
