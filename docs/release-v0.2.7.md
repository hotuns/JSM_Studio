# JSM Studio v0.2.7

本次更新修复 HidHide 授权状态误判，并让游戏视角比例匹配更容易理解。

- 修复点击「允许 JSM 读取手柄」后出现 `HidHide did not confirm JSM access` 的问题：Windows 长路径可能带有 `\\?\` 前缀，而 HidHide 回读为普通路径。现在对应用路径统一处理后比较，正确识别已有授权。
- 同步修正 HidHide 授权状态显示与操作后的验证，兼容普通路径、长路径及 UNC 路径；设备隐藏规则仍按原有逻辑处理。
- 将「真实世界校准」改为「游戏视角匹配（可选）」，解释它用于匹配鼠标输入与游戏转动角度，而不是消除传感器漂移。
- 默认展示「直接调手感」及灵敏度跳转入口，保留当前匹配参数，方便新用户先调整转向快慢。
- 将精确匹配步骤、计算与测量入口、匹配系数和游戏内灵敏度收进可展开的高级区域，并增加 1× / 2× / 4× 转动角度示例。
- 将采样间隔和系统鼠标速度补偿独立为「采样与鼠标兼容」，明确区分视角匹配与静止校准。
- 补齐中英文说明，更新鼠标 Counts 计算窗口及游戏内测量窗口的名称和提示。

本次界面调整保留现有参数和校准算法。展开说明、切换页面不会自动修改配置或触发引擎输出。

继续内置 HidHide 1.5.230 和 ViGEmBus 1.22.0 官方安装程序，映射引擎和 SDL 版本保持不变。

Windows 用户可下载 EXE 或 MSI 安装包；已安装用户可通过应用内更新升级。
