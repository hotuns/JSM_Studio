# JSM Studio v0.2.4

本次更新修复体感映射鼠标时的周期性卡顿，并改进手柄状态和体感设置界面。

- 修复自动连接检查在持有采样锁时等待 20 毫秒的问题，避免未发生设备变化时仍周期性阻塞体感采样和鼠标输出。保持自动连接功能，无需关闭热插拔来绕过问题。
- 将 DualSense 示意图替换为基于 Xbox 结构绘制的通用 SVG 手柄，保留按键、摇杆、扳机和扩展按键的实时状态显示。
- 将体感控制组织为基础设置、灵敏度、防抖与稳定三个分区，并按用途拆分设置卡片。
- 为体感设置和防抖参数增加作用描述及问号帮助按钮，支持键盘操作和 Esc 关闭说明。
- One Euro 开启后展开参数；未启用角度吸附和减速制动时禁用其关联设置。
- 明确平滑阈值、截止频率等单位，将“稳定”更名为“恢复完整输出”，减少参数含义混淆。
- 改进长页面的应用与取消操作，补齐中英文说明。

运行时继续使用 SDL 3.4.18，JoyShockMapper 引擎提交为 `50cd0827d382bbdb6c0051576ee321ff0c0faa6d`。

建议升级后先使用原来的配置验证鼠标移动是否顺畅，再按需要调整滤波。当前 SDL 路径中的频率显示主要反映引擎回调速率，不代表手柄传感器的实际报告频率。

Windows 用户可下载安装 EXE 或 MSI；已安装的用户也可通过应用内更新升级。
