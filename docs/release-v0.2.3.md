# JSM Studio v0.2.3

本次更新精简 Tauri 桌面应用，并升级手柄运行时。

- 移除 AI 助手和调试台，以及对应的后端服务。
- HidHide 改为官方下载链接，移除内置安装器、设备隐藏和白名单管理界面。
- 默认使用普通权限启动；仅在向提权游戏发送输入等场景下按需以管理员身份运行。
- 左侧菜单调整为手柄状态、体感控制、按键映射、触摸板和 JSM 文档。
- 将“陀螺仪与灵敏度”更名为“体感控制”。
- 手柄状态页新增 14 个扩展输入槽位，实时高亮背键、小肩键、摇杆触摸和 MISC 输入，并显示当前按下数量。槽位数量不代表设备实际支持的按键总数。
- SDL 从 3.4.4 升级至 3.4.18，重新构建配套 JoyShockMapper。
- JSM、SDL 和控制台辅助程序静态链接 VC++ 运行库，减少缺少运行库导致的启动问题。
- 构建脚本核对 SDL 版本并生成运行时来源和文件校验记录。

需要 HidHide 的用户请自行下载安装，并在 HidHide 中配置当前 JoyShockMapper.exe 的应用白名单和设备隐藏。

Windows 用户可下载安装 EXE 或 MSI。现有版本也可通过应用内更新升级。
