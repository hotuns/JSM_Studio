# JSM Studio v0.2.6

本次更新简化配置创建流程，提供可直接使用的基础模板，并修复配置库重命名失败的问题。

- 顶部配置下拉框旁新增「新建配置」，与配置库入口共用同一个创建窗口。
- 提供三种起点：光标操作配置、手柄原生映射、空配置。可输入名称，并选择创建后加载到编辑器或仅存入配置库。
- 手柄原生映射可选虚拟 Xbox / DS4，预填常用按键、方向键、双摇杆和模拟扳机，体感默认关闭，无需逐键映射。运行此配置需要 ViGEmBus。
- 在「设置与组件」选择虚拟手柄输出时，先询问是否创建完整映射，同时保留「仅修改当前输出类型」供高级用户使用。
- 修复配置库重命名时 Tauri 参数名不匹配、错误被吞掉的问题。行内使用「保存名称」，支持 Enter 和名称输入框内的 Ctrl+S；失败后保留输入以便重试。
- 重命名保留未保存的映射编辑。当前有未保存修改时，新建配置只保存到配置库，不替换当前编辑。
- 光标操作模板明确关闭虚拟手柄输出，避免沿用之前的虚拟输出模式。
- 补齐新流程的中英文说明，并改进新建窗口在较短窗口中的滚动与底部操作布局。

创建、保存或加载到编辑器不会立即改变正在运行的映射，确认后点击「应用修改」生效。虚拟手柄基础映射仍需在目标游戏中验证；如有双重输入，可在「设置与组件」配置 HidHide。

继续内置 HidHide 1.5.230 和 ViGEmBus 1.22.0 官方安装程序。映射引擎与 SDL 版本保持不变。

Windows 用户可下载 EXE 或 MSI 安装包；已安装用户可通过应用内更新升级。
