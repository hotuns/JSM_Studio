# 设置与组件

在左侧「设置与组件」集中管理驱动、手柄输出、软件更新和运行设置。「设备与输入」页也提供入口。

## 驱动检测与安装

- **HidHide**：避免游戏同时接收原始手柄输入与 JSM 映射输出。
- **ViGEmBus**：当前 JoyShockMapper 用它输出虚拟 Xbox 360 / DS4。键鼠映射及体感鼠标不要求安装它。
- 通过 Windows 服务状态区分未安装、已安装但未运行、运行中、查询失败。运行中不等于已经创建了虚拟手柄，也不替代实际游戏验证。
- 随软件内置官方 HidHide 1.5.230.0 和 ViGEmBus 1.22.0 安装器；未安装时点击「安装驱动」即可启动本地安装向导，无需另行下载。Windows 按需弹出权限提示，主程序没有改成管理员启动。已有驱动时快捷安装按钮禁用，避免误触重装。
- ViGEmBus 已停止维护，链接指向原项目，不引导安装不明来源的替代包。

## 隐藏手柄

1. 安装 HidHide 后点击「重新检测」。有多个手柄时，按名称及 VID/PID 核对设备。
2. 选择实体手柄，点击「隐藏所选手柄」。软件会先将当前安装目录下可用的 SDL / legacy JoyShockMapper 可执行文件添加到允许列表，再加入所选 HID 设备并开启全局隐藏。
3. 若游戏仍识别原始 XInput 手柄，可明确勾选「同时隐藏 XInput / 接收器节点」后重试。这会包含关联的接收器父节点，可能影响其他功能，不默认开启。
4. 重新连接手柄或重启游戏，确认游戏不再收到原始输入，JSM 仍有按键与体感输入。页面显示的是驱动配置，不宣称已验证某个游戏的屏蔽效果。
5. 「恢复所选手柄」和「恢复本软件新增的全部隐藏」仅移除本软件新增的设备节点，保留其他工具原有的规则、应用允许列表及全局开关。被外部规则隐藏的节点仍可能保持隐藏。

隐藏规则是持久的，退出、崩溃或重启不会自动取消。新增规则在执行写入前记录到应用数据目录 `hidhide-studio-rules.json`，下次启动仍可恢复；即使设备已拔掉，仍可使用恢复全部。CLI 操作失败时不会丢弃恢复记录。

共享接收器的依赖会保留：恢复一个设备不会删除另一份 Studio 规则仍然需要的父节点。已有反向应用列表时拒绝自动修改，让用户在官方配置工具确认模式。开启全局隐藏也会激活列表中原有的其他设备规则，界面会提示。

官方配置窗口与 CLI 不能同时占用驱动。打开官方工具后，应关闭它再回到 Studio 检测或修改。旧版 CLI 的中文 JSON 截断问题通过只读 Windows SetupAPI 枚举备用处理，避免从损坏的 JSON 猜测设备节点。

## 虚拟手柄

- 顶部配置下拉框旁的「新建配置」与配置库的新建按钮使用同一个窗口，提供「光标操作配置」「手柄原生映射」「空配置」三种模板。
- 手柄原生映射可选择 Xbox / DS4，预填常用按键、方向键、双摇杆和模拟扳机，体感默认关闭。运行时需要 ViGEmBus；创建离线配置不要求先安装驱动。
- 设置页选择 Xbox / DS4 输出类型时，先询问是否创建完整映射。推荐创建独立配置，也保留「仅修改当前输出类型」供高级用户使用；后者不自动补齐按键。
- 新建时可选择加载到编辑器或仅存入配置库；两种方式均不会立即改变引擎输出，需点击「应用修改」。当前有未保存编辑时，只保存新配置，不替换原编辑。
- 配置库重命名使用行内「保存名称」，支持 Enter 或在名称输入框中按 Ctrl+S。失败时显示提示并保留输入以便重试；名称变更不覆盖未保存的映射内容。
- 虚拟手柄不能直接修改实体手柄的原始信号；双重输入可通过 HidHide 管理。基础配置仍需在目标游戏中核对实际行为。

## 更新及其他

更新页共享全局更新提示的状态，支持手动检查、下载进度、重试、安装并重启及发布页手动下载。检查失败显示具体错误，不将网络失败解释为已是最新；手动检查后，不再用延迟的自动检查覆盖当前状态；安装失败保留已下载状态，可以再次安装。

其他入口包括 SDL / legacy 后端切换、配置文件夹、设备输入检查、语言、主题、官网和问题反馈。切换后端会重启引擎，不会自动应用未保存的编辑。

## 验证

- Rust：`cargo test --lib components::tests`。
- 前端：`npm run test:components`、生产构建及界面交互检查。
- 本机对 HidHide / ViGEmBus 和设备枚举做只读检查，不自动隐藏用户正在使用的手柄、不创建测试虚拟设备、不安装驱动。

## 内置安装包

安装包和许可证位于 `JSM_GUI/jsm_gui_tauri/src-tauri/drivers/`，作为 Tauri 资源打包。构建与开发启动前运行 SHA-256 校验；实际启动安装器前再次校验并锁定文件，避免把损坏的资源作为安装程序运行。

安装由用户点击触发，使用原厂交互式向导，不静默安装、不自动重启 Windows。安装结束、取消或失败后会重新读取驱动状态；需要重启时显示提示。安装过程不改变 JSM Studio 的权限或自动开启隐藏、创建虚拟设备。

「运行与支持」里的语言选择不显示额外图标，侧栏原有语言图标保留。
